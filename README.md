# MukaDepan Studio

Fixed-price, sub-second landing pages for Malaysian SMEs — see your live front page before you pay RM1, live on your domain in 72 hours.

## Stack
- Zero-build static HTML, CSS, and vanilla JavaScript (`index.html`, `styles.css`, `main.js`)
- Self-hosted `DM Sans` and `Newsreader` fonts (`assets/fonts/`)
- Bilingual English / Bahasa Melayu (`EN | BM`) switcher with live interactive Order Desk
- WhatsApp (`011-5440 2412`) + Email (`meerulhazeeq@gmail.com`) + optional webhook hook (`window.MUKADEPAN_WEBHOOK_URL`)
